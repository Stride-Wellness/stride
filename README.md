# Stride

Stride is a elderly care support app. It's intended use if for homecare providers and lifestyle providers in retirements homes. The basic functionality is that a busness buys the app and seats. Then the busness can add providers and clients (elderly adults) with the seats. The works fill out a quiz with the elderly person identifing their goals, problems, etc. Then ChatGPT will come up with an individualized work out for the client. The provider will have a session with client where they show the excersises. Or maybe there will be a very basic mobile app for the client to view the excerises too with the works permision.

Admins and Managers have a web dashboard to manager providers and clients. Workets and clients have a phone dashboard, with a very simple interface to complete quizes and see excersis descriptions and gifs.

Some use cases are:

Grandchild (Bob) wants to help their grandparent (Joe) stay healthy. They buy stride with one seat. They are admin, manager, and Personal Support Provider (PSW). Bob fills out the form with Joe, he says what his goals are and then it gives Bob a list of excerisis to give Joe. Optionally, if fit, Joe can install the app too and only have access to the excersises.

Retirement home owner (Bob) wants to help keep residents healthier. Bob buys Stride with a bunch of seats. Bob has two retirement homes so he assignes a manager to each of them. Bob only pays the bill for th number of seats, but the managers create seats for life style providers and residents. Then managers can also handle invinting providers and residents, if fit. They can manage which providers can view which residents, and have a dashboard of all residents.
